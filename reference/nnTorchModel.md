# Create C++ torch modules for all networks in a model

For each network generated by \[nn()\] in an assembled model, creates a
C++ torch module of the recorded shape. Weights reach the solve via
\[nnUpdate()\], which syncs each attached module into the loader buffer.

## Usage

``` r
nnTorchModel(x, seed = NULL)
```

## Arguments

- x:

  an assembled rxode2 model / ui object built with \[nn()\].

- seed:

  optional integer seed for reproducible initialization.

## Value

invisibly, a data.frame of the created modules.
